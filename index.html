Como ler este diagrama

  • Enquadrar tudo na tela: aperte 0 (ou o botao % do canto). Se ainda precisar rolar, o fluxo e grande — use F para o modo apresentacao em tela cheia.
  • Zoom com qualidade: + e - ampliam sem borrar (e vetor, nao imagem). Para ver o geral, volte com 0.
  • Achar um no: / busca por nome, responsabilidade ou id estavel.
  • Seguir uma chamada: R traca a rota entre dois nos na direcao documentada.
  • Claro/escuro: T troca o tema. E exporta PNG/WebP/SVG.
  • Caixinhas clicaveis: cada no abre detalhes (entradas, saidas, erros). As evidencias entre parenteses (arquivo:linha) apontam o codigo-fonte exato.

Glossario

  • MCP — Model Context Protocol: o canal pelo qual o agente chama tools (pedido/resposta em JSON).
  • Tool / tool call — funcao que o agente invoca; handler valida e executa, service contem a regra de negocio.
  • Escopo (scope) — permissao exigida (read le, write/github:write escreve). Sem escopo, a chamada e recusada antes do banco.
  • Anti-BOLA — checagem de que o chamador so enxerga objetos do proprio projeto (BOLA = acessar objeto alheio trocando o id).
  • Envelope / isError — resposta padrao {ok, data} ou {ok:false, error}; isError avisa a interface que deu erro.
  • Zod — validador dos argumentos (tipo, tamanho, formato) antes de qualquer I/O.
  • Prisma — ORM do banco Postgres; findUnique/findMany leem, transacoes gravam tudo-ou-nada.
  • Transacao / FOR UPDATE — trava a linha durante a escrita para duas execucoes nao se atropelarem.
  • Lease / claim — reserva temporaria ("estou cuidando disso"); idempotente = repetir nao duplica.
  • OIDC / JWT / RBAC — login federado / token de sessao / permissao por papel.
  • SSE / WebSocket — a resposta do modelo desce em eventos de texto ao vivo.
  • FTS / trigram / RRF — busca textual: indice de texto, similaridade de trigramas e fusao de rankings.
