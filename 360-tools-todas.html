结论

O workspace de tools do spaceAI reúne 243 tools. As 24 nativas do motor rodam in-process, com precedência sobre MCP; as outras 219 chegam por servidores MCP: sandbox-agent (24), MyPanel (4), agent-package (163) e render (28).

  1. Cada tool já tem um diagrama validado; a lista abaixo é o índice completo, com o link direto para abrir o interativo.
  2. As 24 nativas do motor saem em ordem alfabética estável e têm precedência sobre qualquer tool de MCP.
  3. O agent-package serve duas famílias no mesmo gateway: core (83) e GitHub (80), mais o render (28) como servidor à parte.
  4. Nove tools do catálogo do core não têm diagrama próprio e estão marcadas como não documentadas.

Como usar este índice

Este índice lista as 243 tools com link direto para cada diagrama validado.

  1. Abra a seção do motor e confira as 24 nativas in-process pelo diagrama.
  2. Abra as 4 tools do MyPanel e veja o roteamento por risco query, mutation e destructive.
  3. Escolha uma tool de task, knowledge, memory, prompt ou skill e siga o caminho completo no diagrama.
  4. Abra uma tool de GitHub e confira o prefixo agentpack_ e o escopo read ou github:write.
  5. Confira a lista de 9 tools sem diagrama e peça as que faltam.

Limites conhecidos

  • ERD agentpack é denso: abra em tela cheia com F e busque com / em vez de rolar.
  • sandbox-agent foi reescrito em Go: nomes e mensagens podem divergir do diagrama antigo.
  • MyPanel tem dezenas de procedures (ex. 84): descubra pela search_procedures, não decore a lista.
  • 9 tools do core seguem sem diagrama e aparecem como não documentado na tabela.
11

Glossário geral

MCP é o canal; motor roda in-process; sandbox-agent mexe na sandbox; MyPanel roteia por risco; agent-package guarda tasks e GitHub fala com prefixo agentpack_.

  • MCP — canal pelo qual o agente chama tools do motor e dos servidores.
  • Motor — 24 tools nativas in-process com precedência sobre MCP.
  • sandbox-agent — 24 tools que mexem em arquivos, processos e previews.
  • MyPanel — 4 tools por risco: query, mutation e destructive.
  • agent-package — core com 83 diagramas e GitHub com 80 e prefixo agentpack_.
  • Render — 28 tools de telas, revisões e catálogo.
